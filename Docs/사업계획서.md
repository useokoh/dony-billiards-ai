# 큐니 앱 신규 기능 "AI 샷 코칭" 사업계획서

> 한 줄 소개: **큐니 앱에 메뉴 하나를 더해, 내 경기 영상을 이닝·샷으로 자동 정리하고 실패한 샷마다 "다음엔 이렇게 치라"고 알려 주는 3쿠션 코칭 기능**입니다. 기본 기능은 무료로 이용자를 모으고, 교정 코칭은 **큐니 앱의 캔디**로 이용합니다.

---

## 1. 요약

| 항목 | 내용 |
|---|---|
| 무엇을 | 내 경기 영상 자동 정리 + 실패 샷 교정 코칭 |
| 어디에 | **큐니 앱 안에 기능 추가** (새 앱, 새 장비, 새 매장 계약 없음) |
| 누구에게 돈을 받나 | **당구 치는 사람.** 구장(당구장)에서 돈을 받지 않는다 |
| 어떻게 돈을 버는가 | 기본 기능은 무료로 이용자를 모으고, 교정 코칭은 큐니 캔디로 이용 → **캔디의 새 사용처** |
| 왜 필요한가 | ① 하이런 이벤트로 주 1,000만 원씩 나가는 캔디를 **다시 사게 만들 소비처**를 만든다 ② 이용자를 늘린다 ③ 재미를 덜 느끼는 초보가 실력이 느는 경험을 하게 돕는다 |
| 지금 어디까지 왔나 | 동작하는 시제품 완성. 실제 경기 영상 2개(48분·58분), 샷 219개로 자동 정리·판정·코칭 검증 |
| 요청 사항 | 큐니 앱 탑재 + 초기 개발·운영 자금 1억 원 (12장 참고) |

## 2. 문제

1. **초보는 당구가 금방 재미없어진다.** 왜 안 맞는지 모른 채 계속 놓치면 흥미를 잃고 그만둔다. 옆에서 가르쳐 줄 고수가 늘 있는 것도 아니다.
2. **경기를 돌아볼 방법이 없다.** 한 경기에 50~60번 큐를 들지만, 끝나면 점수만 남는다. 어떤 샷을 왜 놓쳤는지 기록이 없다.
3. **영상이 있어도 쓰기 어렵다.** 1~2시간 영상에서 "17이닝 4번째 샷"을 찾으려면 직접 앞뒤로 돌려 봐야 한다.
4. **점수만으로는 무엇을 고칠지 모른다.** "쿠션이 2개라서 실패"는 결과일 뿐, 두께를 얼마나 바꿔야 했는지는 알려 주지 않는다.
5. **캔디는 나가는데 들어오지 않는다.** 캔디 사용처는 경기 영상 다운로드와 하이런 이벤트 정도다. 하이런 이벤트 보상으로 **일주일에 약 1,000만 원어치 캔디가 빠져나가지만**, 쓸 곳이 적어 이용자의 캔디 구매율은 낮다.

> 1~4는 동호인·초보 인터뷰로 크기를 확인할 예정입니다 (10장 1단계).

## 3. 솔루션

### 3.1 이용자가 보는 화면

| 기능 | 무료 / 캔디 | 설명 |
|---|---|---|
| 이닝·샷 자동 정리 | 무료 | 3쿠션 대회 규칙(선공·후공이 한 번씩 치면 1이닝)대로 이닝과 샷을 나누고 점수를 센다 |
| 샷 목록 나눠 보기 | 무료 | 전체 / 득점 / 실패 / 확인 필요로 나눠 바로 찾는다 |
| 샷 영상 바로 보기 | 무료 | 샷 시작부터 공이 멈출 때까지만 잘라 바로 재생한다 |
| 실제 경로 그림 | 무료 | 공 3개가 실제로 어떻게 움직였는지 당구대 그림에 그린다 |
| 자동 판정 + 직접 확인 | 무료 | 득점·실패와 실패 이유를 자동 판정한다. 근거가 엇갈린 샷만 "확인 필요"로 표시하고, 이용자가 인정·불인정을 누르면 그 값이 우선한다 |
| **내가 친 경로 교정** | 캔디 | 실패한 샷에서 **같은 1적구·같은 쿠션 순서를 유지한 채** 두께를 몇 도 바꾸고 얼마나 세게 쳐야 득점이었는지 알려 준다 |
| 더 쉬운 다른 경로 | 캔디 | 교정보다 확실히 쉬운 경로가 있을 때 하나 더 보여 준다 (초보에게 특히 유용) |
| 실행 가이드 | 캔디 | 1적구 두께, 쿠션 순서, 권장 회전·당점·강약을 그림과 표로 보여 준다 |

무료 기능만으로도 "내 경기를 정리해서 다시 보는" 가치가 있어 이용자가 모이고, 그중 실력을 올리고 싶은 사람이 캔디로 코칭을 씁니다.

### 3.2 코칭 예시 (실제 시제품 출력)

> 친 경로(빨간공 먼저 → 단·장·장·단) 그대로 득점할 수 있습니다. 흰공을 약 5cm 차이로 놓쳤습니다. 같은 약 1/2 두께 안에서, 자르는 각 약 37.9° → 33.5°(약 4.4° 더 두껍게) 맞히세요. 2적구 근처에서 공이 거의 멈췄으니 힘이 모자랐을 가능성이 큽니다. 한 단계 더 세게 치세요.

이용자가 가장 듣고 싶은 말은 "다른 길로 쳐라"가 아니라 **"네가 친 그 길에서 이것만 바꿔라"**라는 점에 맞췄습니다.

### 3.3 초보를 위한 설계

- **"5cm 차이로 놓쳤다"처럼 아깝게 놓친 정도를 보여 준다.** 실패가 아니라 "거의 다 왔다"는 느낌을 줘서 다시 치고 싶게 만든다.
- **어려운 회전보다 두께·세기부터.** 초보가 바로 따라 할 수 있는 두 가지만 먼저 바꾸게 한다.
- **더 쉬운 길도 함께.** 같은 배치에서 성공 확률이 높은 기본 3쿠션 경로를 보여 준다.
- **첫 코칭 무료.** 처음 몇 번은 캔디 없이 써 보고 효과를 느끼게 한다.

### 3.4 필요한 것: 앱에 기능만 추가하면 된다

**새로 설치할 장비도, 새로 계약할 매장도 없습니다.** 큐스코가 설치된 구장에는 이미 경기 영상을 찍는 카메라가 있고, 이용자는 이미 큐니 앱으로 자기 경기 영상을 봅니다. 우리는 그 영상과 그 앱을 그대로 씁니다.

```
[이미 있는 것]                                  [우리가 더하는 것]
구장 카메라 ─▶ 큐스코 시스템 ─▶ 내 경기 영상 ─▶ 분석 서버(우리) ─▶ "AI 샷 코칭" 화면
                                  큐니 앱 ◀──────────────────────────┘ (메뉴 하나 추가)
```

| 비교 | 일반적인 신규 서비스 | 큐니 앱 기능 추가 |
|---|---|---|
| 장비 | 당구대마다 카메라 설치 | **설치비 0원**, 기존 카메라 영상 사용 |
| 이용자 앱 | 새 앱 설치·가입 | **이미 쓰는 큐니 앱에 메뉴 하나** |
| 매장 | 매장마다 영업·계약·설치 | **필요 없음.** 앱 업데이트 한 번으로 모든 이용자에게 적용 |
| 결제 | 새 결제 수단 | **큐니 기존 캔디 그대로** |

- 지금 시제품은 빠르게 검증하려고 웹으로 만들었습니다. **큐니 앱에 넣을 때는 화면을 앱으로 옮겨 만듭니다.** 영상 분석 서버와 데이터 API는 그대로 쓰므로 화면만 새로 만들면 됩니다.
- 시제품에는 영상 올리기 화면도 있어, 앱 연동 전에도 바로 시험할 수 있습니다.

## 4. 시제품 현황과 검증 결과

이미 동작하는 시제품이 있습니다. 아래 수치는 실제 3쿠션 경기 영상 2개를 처음부터 끝까지 돌려 얻은 값입니다.

| 항목 | 결과 |
|---|---|
| 검증 영상 | 실제 경기 2개, 48분·58분 (30fps, 당구대 위쪽 카메라) |
| 자동 정리 | 샷 219개, 55이닝으로 자동 분리하고 경기 점수 산출 (32:22, 26:32) |
| 분석 시간 | 58분 영상 → 약 6분 (노트북 1대, 별도 GPU 없음) |
| 판정 근거 일치 | 219개 중 214개(97.7%)는 공 움직임 판정과 다음 차례 판정이 일치. 엇갈린 5개만 직접 확인으로 넘김 |
| 재분석 일관성 | 같은 영상을 지우고 다시 올렸을 때 샷 117개의 판정·쿠션·충돌 순서가 모두 같음 |
| 실제 두께 측정 | 득점한 샷에서 영상으로 잰 두께와 모델이 계산한 득점 두께의 차이 중앙값 0.2° |
| 교정 코칭 적용 | 측정 가능한 실패 샷 84개 중 52개(62%)에 "친 경로 그대로" 교정안 제공 |
| 기술 구성 | 영상 분석(Python·OpenCV), 서버(NestJS), DB(SQLite), 휴대폰 웹(Next.js) |
| 앱 연동 준비 | 분석 서버와 API가 화면과 분리되어 있어, 큐니 앱 화면에서 그대로 호출 가능 |

**아직 부족한 점 (숨기지 않고 밝힙니다)**

- 추천 경로가 실제 공 움직임을 끝까지 재현하는 비율은 아직 18~46% 수준이라 코칭은 "권장값"으로 표시합니다.
- 영상만으로는 실제 회전·힘을 판정하지 못합니다. 회전·당점은 득점에 유리한 추천값으로만 제공합니다.
- 검증 영상이 한 당구장의 한 당구대뿐입니다. 여러 구장의 카메라 각도·조명으로 다시 검증해야 합니다.

**어떻게 좋아지나: 큐니의 경기 데이터로 AI 모델을 학습시킨다**

지금 분석 엔진은 영상 처리와 실측으로 보정한 물리 모델입니다. 큐니는 이미 수많은 구장의 경기 영상과 기록을 가지고 있습니다. 이 데이터와 이용자가 누른 인정·쫑 확인 기록을 정답으로 삼아 AI 모델을 학습시키면, 공 인식이 구장 환경에 덜 흔들리고 추천 경로 재현율과 코칭 품질이 올라갑니다. 다른 회사가 쉽게 따라올 수 없는 **데이터 기반 경쟁력**이 됩니다.

## 5. 시장

### 5.1 누가 쓰나

| 이용자 | 무엇을 얻나 | 캔디를 쓰는 이유 |
|---|---|---|
| 초보 (흥미를 붙이는 단계) | 왜 안 맞는지 알고, "거의 맞았다"는 성취감 | 무료 체험 뒤 실력이 느는 게 보여서 |
| 중수 동호인 | 내 실패 습관과 교정값 | 동호회 경기·리그에서 이기려고 |
| 고수 | 경기 기록 정리와 복기 | 주로 무료 기능, 중요한 경기만 코칭 |

### 5.2 시장 규모 (가정)

- 큐니 앱 월 이용자를 **10만 명**으로 가정합니다 (큐스코 내부 자료로 확인 필요).
- 이용자 전체가 한 달에 교정 리포트를 한 번(1,500원)만 써도 **연 18억 원 규모**의 캔디 사용이 생깁니다.
- 3년 차에는 월 이용자의 8%(8,000명)가 매달 캔디로 코칭을 쓰는 것을 목표로 합니다.

### 5.3 시장 흐름

- 프로당구 출범 이후 3쿠션 중계와 동호인 대회가 늘면서, 자기 경기를 "프로처럼" 돌아보려는 수요가 생기고 있습니다.
- 동호인은 이미 큐니로 자기 경기 영상을 봅니다. **보는 것에서 고치는 것으로** 한 걸음만 더 가면 됩니다.

## 6. 경쟁과 차별성

### 6.1 비교 대상

| 서비스 | 강점 | 약점 |
|---|---|---|
| 빌리보드 | 넓은 보급 규모, 기록·운영 관리, 경기 영상 | 앱 화면, 일부 iOS 불편 |
| 빌리존 | 앱 안정성과 속도 | 로그인·영상 재생 오류 불만 |
| 유튜브 강좌·레슨 | 다양한 기술 설명, 1:1 지도 | 내 경기·내 실수에 맞춘 설명이 아님, 레슨은 비쌈 |

> 점수판 앱의 특징은 초기 시장조사 원본 자료 기준이며 현재 기능은 다시 확인해야 합니다.

### 6.2 우리가 다른 점

1. **"다시 보기"가 아니라 "고치는 법"을 준다.** 영상 보기는 흔하지만, 실패한 샷을 이닝·샷 단위로 찾아 두께와 세기를 몇 도·몇 단계로 알려 주는 기능은 드뭅니다.
2. **내 경기, 내 실수에 맞춘다.** 유튜브 강좌는 남의 배치를 설명하지만, 우리는 내가 방금 놓친 그 배치를 교정합니다.
3. **내가 친 길 그대로 교정한다.** 전혀 다른 정답 경로를 보여 주면 따라 하지 못합니다. 자기 선택을 존중한 교정이 실제로 다음 샷을 바꿉니다.
4. **설치·계약이 필요 없다.** 큐니 앱 업데이트 한 번이면 모든 이용자에게 바로 적용됩니다.
5. **설명 가능한 판정.** 왜 득점·실패로 판정했는지 근거가 남고, 근거가 엇갈리면 이용자에게 확인을 요청합니다.

## 7. 수익 모델: 무료로 모으고, 큐니 캔디로 이용한다

### 7.1 이용자를 모으는 수단

| 수단 | 내용 |
|---|---|
| 기본 기능 무료 | 경기 자동 정리, 이닝·점수, 샷 영상, 실제 경로 그림은 누구나 무료 |
| 첫 코칭 무료 | 처음 3번은 캔디 없이 교정 코칭 체험 |
| 초보 미션 | "이번 주 아깝게 놓친 샷 3개 다시 성공하기" 같은 미션, 달성하면 캔디 보상 |
| 친구 초대 | 초대한 사람과 가입한 사람 모두 캔디 지급 |
| 결과 공유 | "내 실패 샷 교정" 카드를 메신저·SNS로 공유 → 자연스러운 앱 홍보 |
| 성장 랭킹 | 득점률이 가장 많이 오른 이용자 랭킹, 월간 상위자 캔디 보상 |

### 7.2 큐니 캔디의 새 사용처 (가정)

| 사용처 | 비용 (원 환산) | 비고 |
|---|---|---|
| 경기 영상 다운로드 | 기존 캔디 사용처 | 이미 있음 |
| 하이런 이벤트 | 기존 캔디 사용처 | 이미 있음, 보상으로 주 약 1,000만 원어치 캔디 지급 |
| **경기 1개 "실패 샷 교정 리포트"** | 1,500원 상당의 캔디 | 모든 실패 샷 교정 + 더 쉬운 경로 |
| **샷 1개 교정만 보기** | 200원 상당의 캔디 | 아깝게 놓친 샷 하나만 볼 때 |
| **월간 성장 리포트** | 3,000원 상당의 캔디 | 한 달 실패 유형·득점률 변화 정리 |

- 하이런 이벤트로 캔디는 주 약 1,000만 원(연 약 5억 2,000만 원)어치 나가는데, 쓸 곳이 적어 사는 캔디는 적습니다. **코칭이 새 소비처가 되어 캔디 구매를 늘립니다.**
- 3년차 코칭 캔디 매출(4억 3,200만 원)이면 하이런 이벤트로 나가는 캔디의 **약 83%를 다시 채웁니다.**
- 구장과 매출을 나누지 않습니다. 이용자가 앱에서 캔디를 쓰는 것이 곧 매출입니다.

> 캔디 단가와 기능별 가격은 이 계획서의 가정입니다. 큐니 앱의 캔디 가격 체계에 맞춰 확정합니다.

## 8. 출시·확대 전략

1. **기존 이용자에게 먼저.** 큐니 앱 업데이트로 "AI 샷 코칭" 메뉴를 열고, 이미 경기 영상을 보는 이용자에게 첫 코칭 무료를 알린다.
2. **초보에게 집중한다.** 가입 3개월 이내 이용자에게 초보 미션과 무료 코칭을 우선 제공해 흥미를 붙이게 한다.
3. **동호회로 넓힌다.** 동호회 리그·성장 랭킹으로 동호회 단위 이용을 늘린다.
4. **이용자가 이용자를 데려오게 한다.** 결과 공유와 친구 초대로 새 이용자를 모은다.

## 11. 재무 계획 (3년, 가정)

| 항목 | 1년차 | 2년차 | 3년차 |

| 매달 캔디로 코칭을 쓰는 이용자 (평균) | 1,000명 | 3,000명 | 8,000명 |
| 코칭 캔디 매출 | 2,700만 원 | 1억 6,200만 원 | 4억 3,200만 원 |
| 인건비 (연 4,000만 원/인) | 2명, 8,000만 원 | 3명, 1억 2,000만 원 | 5명, 2억 원 |
| 서버·영상 분석 비용 | 1,000만 원 | 3,000만 원 | 6,000만 원 |
| 무료 코칭·미션 보상 (이용자 유입) | 1,000만 원 | 2,000만 원 | 4,000만 원 |
| 장비·매장 비용 | 0원 | 0원 | 0원 |
| **영업이익** | **-7,300만 원** | **-800만 원** | **+1억 3,200만 원** |

- 코칭 캔디 매출 = 이용자 수 × 이용자당 월 4,500원(교정 리포트 3회) × 12개월 (1년차는 출시 후 6개월).
- 장비와 매장 비용이 없어서, 이용자가 늘수록 이익이 빠르게 커집니다.
- **2년차에 거의 손익분기, 3년차에 흑자**입니다. 1~2년차 누적 적자는 약 8,100만 원입니다.

## 14. 할 수 있다는 근거

- 영상 분석, 서버, DB, 휴대폰 화면까지 **시제품 전체를 직접 만들어 실제 경기 영상으로 동작시켰습니다.**
- 영상 → 자동 분석 → 이닝·샷 정리 → 실패 샷 교정까지 한 흐름으로 시연할 수 있습니다.
- 분석 서버와 화면을 나눠 만들어, 큐니 앱 화면만 새로 만들면 그대로 연결할 수 있는 구조입니다.

## 부록 A. 시연 순서 (5분)

1. 내 경기 화면에서 영상 올리기와 진행률을 보여 준다 (큐니 연동 전 시험 방식).
2. 분석된 경기를 열어 이닝·샷 자동 정리와 점수를 보여 준다 (무료 기능).
3. 샷 목록을 득점 / 실패 / 확인 필요로 나눠 본다.
4. "확인 필요" 샷의 샷 영상을 보고 인정을 누른다.
5. 실패 샷의 코칭 탭에서 "내가 친 경로 교정"과 점선 경로를 보여 준다 (캔디 기능).

## 부록 B. 출처와 확인 필요 사항

- 큐니 앱: 큐스코가 큐스코 설치 구장 이용자를 위해 만든 개인용 앱으로, 자기 경기 영상 시청 기능이 있다(앱스토어 소개 기준). 큐니의 캔디는 경기 영상 다운로드에 쓰인다. 캔디 가격 체계는 큐스코 자료로 확인.
- 하이런 이벤트 캔디 지급 규모(주 약 1,000만 원): 큐니 운영 현황 기준 발표자 조사 수치.
- 큐니 앱 월 이용자 수: 가정값. 큐스코 내부 자료로 확인 필요.
- 점수판 앱 특징: 초기 시장조사 원본 자료. 현재 기능 재확인 필요.
- 코칭 가격, 전환율, 재무 계획: 이 계획서의 가정이며 수요 확인 단계에서 검증.
- 시제품 수치: 실제 경기 영상 2개 분석 결과 (2026년 11월).
