## 2026-11-23 AI 샷 코칭 발표 자료(HTML·PPTX)와 대본
- 한 일: 사업계획서(큐니 앱 기능 추가, 캔디 소비처) 기준으로 16장 발표 자료를 새로 만들었다. `Project/HTML/발표자료/index.html`(←→ 이동, N 발표 메모, F 전체 화면, `?s=번호`로 바로 열기), `Project/PPTX/AI샷코칭_발표자료.pptx`(슬라이드 그림 + 6번에 실제 샷 영상 + 슬라이드별 메모), `Docs/발표대본.md`(순서·시간표, 시연 준비, 대본, 예상 질문).
- 결정과 이유: 앱 화면과 이어지도록 v3(검정·빨강) 대신 앱 디자인(진한 남색, 당구대 천 색, 하늘색 강조, 공 색)을 썼다. 앱 화면은 앱 안 브라우저를 390×844 휴대폰 크기로 맞춰 캡처했고(개발 표시 "N"은 숨김), 영상은 1이닝 6번째 실패 샷(교정 예시와 같은 샷)을 1280px로 줄여 넣었다(`assets/`). PPTX는 headless Chrome으로 찍은 1920×1080 그림을 pptxgenjs로 넣었다(편집용 아님).
- 문제와 해결: 캡처 중 휴대폰 크기 설정이 풀려 다시 맞췄다. 8번 슬라이드 그림 설명이 쪽 번호와 겹쳐 설명을 카드 안으로 옮겼고, 내용이 적은 슬라이드는 세로 가운데 정렬했다. 앱 안 브라우저는 로컬 파일을 열 수 없어 headless Chrome으로 16장을 찍어 확인했다.
- 확인 결과: 16장 모두 겹침 없음, PPTX에 슬라이드 16장·영상·메모 포함. 대본 약 10분 + 시연 약 2분. HTML은 글꼴(Pretendard)을 인터넷에서 받으므로 오프라인이면 기본 글꼴로 보인다. PowerPoint·Keynote에서 직접 열어 보지는 않았다.

- 확인 결과: 파일 구조 검사와 Mac 미리보기만 확인했다. PowerPoint에서 직접 열어 보지 않았다. 기획서 8장 내용은 슬라이드에 없다.
