# 기획 문서

## 2026-11-23 사업계획서 3차 피드백 반영(마무리)
- 하이런 이벤트로 캔디가 주 약 1,000만 원 나가지만 소비처가 적어 구매율이 낮다는 점, 큐니 탑재 시 웹 화면을 앱으로 옮겨 만든다는 점, 큐니 경기 데이터로 AI 모델을 학습시켜 코칭·재현율을 높인다는 점을 넣었다. 3년차 코칭 캔디 매출이 하이런 이벤트 유출의 약 83%를 채운다는 비교를 추가했다.

## 2026-11-23 사업계획서 2차 피드백: 큐니 앱 기능 추가 + 캔디 소비처로 전면 수정
- 결정과 이유: 사용자 설명 — 이 서비스는 큐니 앱(큐스코의 개인용 앱)에 기능을 추가하는 것이고, 큐니에는 이미 "캔디"라는 앱 내 화폐가 있으며 경기 영상 다운로드에 캔디를 쓴다. 피드백(교정 코칭)을 캔디의 새 소비처로 만들고, 더 많은 사용자 유입과 흥미를 덜 느끼는 초보 지원이 목적이다. 돈은 구장이 아니라 당구 치는 사람에게서 번다. 시범 매장과 매장 매출 배분은 필요 없다. 11월 2일 출시된 큐니 AI는 이 기획 이후에 나왔고 교수님도 알고 있어 계획서에서 다루지 않는다.
- 한 일: `Docs/사업계획서.md`를 "큐니 앱 신규 기능 AI 샷 코칭"으로 다시 썼다. 기본 기능 무료 / 교정 코칭은 캔디, 초보를 위한 설계(3.3), 앱에 기능만 추가(3.4), 이용자층별 사용 이유, 캔디 새 사용처와 가격(가정), 핵심 지표, 재무(장비·매장 비용 0, 3년차 +1억 3,200만 원), 요청 사항(앱 탑재 + 1억 원)으로 바꿨다. 매장·프랜차이즈·시범 매장·매출 배분 내용은 모두 뺐다.
- 확인 결과: 앱스토어 페이지로 큐니가 큐스코 설치 구장 이용자의 경기 영상 시청 앱임은 확인. 캔디·영상 다운로드 가격은 페이지에 없어 사용자 설명을 따랐다. 큐니 월 이용자 10만 명은 가정. 재무 계산 재확인.

## 2026-11-23 사업계획서 1차 피드백 반영 (코인 모델, 설치비 없음)
- 결정과 이유: 사용자 피드백 ① 수익 모델을 "이용자 유입 수단 + 자체 코인 이용"으로, ② 설치 방식을 "이미 설치된 카메라·점수판 앱에 기능만 추가, 설치비 없음"을 강점으로 강조하도록 바꿨다.
- 한 일: 기본 기능 무료·첫 코인·방문 적립·친구 초대·결과 공유·동호회 랭킹을 유입 수단으로, 교정 리포트 20코인(2,000원)·샷 1개 3코인 등 코인 상품과 매출 배분(우리 60%, 점수판 앱 25%, 매장 15%)을 넣었다. 코인은 서비스 전용 충전식 이용권(가상자산 아님)으로 명시하고 규제 검토를 위험에 넣었다. 첫 파트너를 프랜차이즈 본사에서 점수판 앱 기업으로 바꿨다. 재무를 다시 계산(장비 원가 0, 3년차 +2,880만 원, 누적 적자 약 2억 700만 원)하고 요청 자금을 2억 5,000만 원으로 바꿨다.
- 확인 결과: 재무·시장 규모 계산 재확인. 기존 카메라 보급 규모와 화각은 파트너사 자료로 확인 필요로 부록에 남김.

## 2026-11-23 사업계획서 작성
- 한 일: 교수님 앞에서 판매 발표를 하기 위한 `Docs/사업계획서.md`를 새로 썼다. 요약, 문제, 솔루션, 시제품 검증 결과, 시장, 고객, 경쟁·차별성, 가격, 진입 전략, 실행 일정, 3년 재무, 요청 사항(시범 매장 3곳·초기 자금 2억 원), 위험, 시연 순서로 구성했다.
- 결정과 이유: 제품 설명은 현재 시제품 기준(레벨 구분 없음, "내가 친 경로 교정" 중심, 업로드·삭제)으로 맞췄다. 시제품 수치는 실제 측정값만 쓰고(샷 219개, 판정 근거 일치 97.7%, 58분 영상 약 6분 분석, 교정 적용 62%, 경로 재현율 18~46%), 한계도 밝혔다. 당구장 수는 공식 최신 통계를 못 찾아 언론 보도(약 2만 개, 프로당구 출범 이전)를 출처와 함께 쓰고, 가격·원가·재무는 모두 "가정"으로 표시했다. "학교·과제" 표현은 쓰지 않았다.
- 확인 결과: 재무표 합계와 시장 규모 계산을 다시 계산해 맞춤. 발표 슬라이드(사업소개서 v3)에는 아직 반영 안 함.

## 2026-11-09 플랫폼·동영상 업로드 전략 정리
- 결정: 시제품은 설치 없이 QR·링크로 여는 **모바일 웹**으로 분석 결과와 실패 샷 코칭을 제공한다.
- 이유: 현재 핵심 가치는 앱 설치가 아니라 영상 분석과 핸디별 코칭이며, 기존 점수판 앱에는 웹뷰로 붙이기 쉽다.
- 대용량 영상: 1~2시간 경기 영상은 휴대폰 브라우저에서 업로드가 중단될 수 있으므로, 초기에는 당구장 카메라·Mac·분석 장치에서 저장·업로드하고 이용자는 웹에서 결과를 확인한다.
- 확장: 사용자가 휴대폰에서 직접 촬영·업로드하는 수요가 확인되면 PWA 또는 네이티브 앱으로 백그라운드 업로드·재시도·푸시 알림을 추가한다.
