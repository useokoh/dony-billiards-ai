# 기획 문서

## 2026-11-09 플랫폼·동영상 업로드 전략 정리
- 결정: 시제품은 설치 없이 QR·링크로 여는 **모바일 웹**으로 분석 결과와 실패 샷 코칭을 제공한다.
- 이유: 현재 핵심 가치는 앱 설치가 아니라 영상 분석과 핸디별 코칭이며, 기존 점수판 앱에는 웹뷰로 붙이기 쉽다.
- 대용량 영상: 1~2시간 경기 영상은 휴대폰 브라우저에서 업로드가 중단될 수 있으므로, 초기에는 당구장 카메라·Mac·분석 장치에서 저장·업로드하고 이용자는 웹에서 결과를 확인한다.
- 확장: 사용자가 휴대폰에서 직접 촬영·업로드하는 수요가 확인되면 PWA 또는 네이티브 앱으로 백그라운드 업로드·재시도·푸시 알림을 추가한다.
