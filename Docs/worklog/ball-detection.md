## 2026-11-09 추천 경로 모델 실측 보정 (route_model.py)
- 한 일: `analyzer/route_model.py`가 두 영상에서 수구의 쿠션 반사 496회, 첫 목적구 충돌 약 100회, 1적구 이동 거리를 재서 `data/results/route_model.json`을 만든다. 백엔드는 이 값으로 수구를 굴려 추천 경로를 찾는다.
- 결정과 이유:
  - 사용자가 "추천 경로 신뢰도 늘리기"를 지시했다. 숫자만 바꾸지 않고 모델을 실측으로 보정한 뒤, 재현율을 측정값으로 신뢰도에 쓰기로 했다.
  - 쿠션 반사 모델 비교(영상별 교차 검증, 오차 중앙값): 거울 반사 14.0°, 직선 β=aα+b 5.0°, 직선+속도 5.4°, 쿠션 순번별 직선 4.7°, **10° 구간 중앙값 표 2.7°** → 표를 골랐다.
  - 충돌 뒤 수구 방향은 충돌 직후(회전으로 휨) 대신 출발점 → 다음 사건(쿠션·공) 직선으로 잰다.
- 확인 결과(교차 검증): 득점 샷 99개 경로 재현율 21% → 46%, 쿠션 접점 오차 13.4cm → 6.9cm. 파이썬 테스트 96개 통과(새로 5개, 실측 표가 거울 반사보다 나은지 회귀 테스트 포함).
- 발견: 실제 수구 꺾임은 두께와 크게 상관없이 대략 17~47°였다(무회전 공식은 두꺼울수록 80° 가까이). 선수들이 끌기·밀기를 쓰기 때문으로 보인다. 꺾임 잔차가 약 10°로 커서 회전을 따로 추정하지 않는 한 한계가 있다.
- 실패한 시도: 처음에는 충돌 직후 4~12프레임 방향으로 검증해 재현율이 거울 22% / 직선 21%로 차이가 없었다. 충돌 직후 휘는 구간 때문이었다.

    - 2398.8초(영상1) 흰공: 멈춰 있고 잘 보이지만 큐에 붙어 놓침. 앞뒤 10프레임까지 계속 놓치는 실제 약점
