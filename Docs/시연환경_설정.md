# 학교 컴퓨터 시연 설정

교수님 요청으로 라이브 시연을 학교 컴퓨터에서 한다. 학교 컴퓨터에는 Node.js만 있으면 되는 **시연용 폴더**를 만들어 쓴다.

## 시연용 폴더 만들기 (내 맥북에서)

```bash
cd ~/DSTITCLASS && bash billiards-ai/demo/make-demo-bundle.sh
```

- 결과: `Project/시연용_당구AI/` (약 600MB). 이 폴더를 USB에 **통째로** 복사한다 (zip으로 묶으면 한글 파일 이름이 깨질 수 있음).
- 들어 있는 것: 커밋된 코드(api, web), DB, 샷 영상, 경로 모델, `start-demo.bat`(Windows), `start-demo.command`(Mac), `사용법.txt`
- 빠진 것: Python·OpenCV·FFmpeg와 경기 원본 영상. 새 영상을 올려 분석할 때만 필요하다. 그래서 학교 컴퓨터에서는 "영상 올리기"를 화면으로만 보여 준다.
- 코드를 고치면 **커밋한 뒤** 다시 만들어야 반영된다 (커밋된 코드만 들어감).

## 학교 컴퓨터에서 (사용법.txt 내용)

```text
당구 AI 시연 - 학교 컴퓨터에서 켜는 법

[미리 할 일] 발표 전날이나 당일 아침에 1~3번을 한 번 해 두세요. 3번 첫 실행에 인터넷과 5~10분이 필요합니다.

1. Node.js 설치 (이미 있으면 건너뛰기)
   - https://nodejs.org 에서 "LTS" 버전을 받아 설치합니다.
   - 관리자 권한이 없어 설치가 안 되면:
     같은 사이트의 다운로드 페이지에서 "Windows Binary (.zip)" (x64)를 받아 압축을 풀고,
     풀린 폴더 안의 내용물을 이 폴더 안 "node" 폴더에 넣습니다.
     (node 폴더 안에 node.exe 가 바로 보여야 합니다)

2. 이 폴더(시연용_당구AI)를 통째로 학교 컴퓨터에 복사합니다.
   - 바탕화면이나 D 드라이브처럼 경로가 짧은 곳이 좋습니다.
   - USB에서 바로 실행하지 말고 컴퓨터에 복사한 뒤 실행하세요 (느림).

3. start-demo.bat 를 더블클릭합니다.
   - 처음에는 패키지 설치와 빌드를 합니다 (5~10분, 인터넷 필요).
   - 끝나면 검은 창 두 개(서버, 화면)가 뜨고 브라우저에서 http://localhost:3000 이 열립니다.
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누릅니다.
   - 방화벽 허용 창이 뜨면 "허용"을 누릅니다.
   - 두 번째부터는 설치 없이 10초 안에 켜집니다.

4. 휴대폰 화면처럼 보이게 하기
   - Chrome 또는 Edge에서 F12 → 왼쪽 위 휴대폰 모양 아이콘(Ctrl+Shift+M) → 기기에서 iPhone 선택.

5. 시연 순서
   - 11월 1일 19:38 경기 → 1이닝 6번째 샷 → 코칭 탭: 내가 친 경로 교정
   - 11월 1일 20:29 경기 → 12이닝 1번째 샷 → 샷 피드백 탭: 인정·불인정
   - 경기 영상 올리기는 버튼과 화면만 보여 주세요. 이 폴더에는 영상 분석 프로그램(Python)이 없어서 실제로 올리면 분석 단계에서 실패합니다.

6. 끝내기: 검은 창 두 개를 닫습니다.

문제가 생기면
   - "Node.js가 없습니다": 1번을 다시 확인하세요.
   - 설치 중 오류: 인터넷 연결(학교 방화벽)을 확인하고 start-demo.bat 를 다시 실행하세요.
   - 화면이 비어 있거나 "백엔드에 연결하지 못했습니다": "서버" 검은 창이 떠 있는지 확인하세요.
   - 3000번 또는 4000번 포트를 다른 프로그램이 쓰고 있으면 켜지지 않습니다. 컴퓨터를 다시 시작한 뒤 실행하세요.
```
